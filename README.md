## About Nuvote

**Nuvote** is a modern Android notes and task management application designed to help users organize their ideas, manage daily activities and keep important information in one place.

With a clean interface and customizable features, Nuvote provides a simple and convenient experience for managing notes and tasks.

## Features

### Notes Management
- Create and add new notes.
- Edit and update existing notes.
- Delete unwanted notes.
- Share notes with others.
- Pin important notes for quick access.
- Organize notes into folders.
- Customize individual notes using different colors.

### Task Management
- Create and manage daily tasks.
- Organize activities in a dedicated Tasks section.

### Personalization
- Light Mode and Dark Mode.
- Adjustable font size.
- Multiple note color options.
- Clean and modern user interface.

### Display & Navigation
- Grid View for visual note organization.
- List View for a compact layout.
- Switch between Grid and List views.
- Dedicated Notes, Tasks, Folders and Settings sections.
- Simple bottom navigation.

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/mohamedriyaz247/Nuvote.git
```

### 2. Open the Project

1. Open Android Studio or a compatible Android development environment.
2. Select **Open Project**.
3. Choose the cloned `Nuvote` folder.
4. Allow Gradle synchronization to complete.

### 3. Build and Run

1. Connect an Android device or start an emulator.
2. Build the application.
3. Run Nuvote on your Android device.
